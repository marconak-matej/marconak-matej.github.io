☕ JVM Corner

☕ Java 27 in IntelliJ IDEA Java 27 introduces nine JEPs, while IntelliJ IDEA adds support for the latest JDK and its evolving features.

  • Java 27 contains nine JEPs, including four final features.
  • Four preview features and one incubator feature continue to evolve.

🧵 Java 21: the foundation for Quarkus 4 Quarkus 4 raises its Java baseline to 21, simplifying virtual-thread support and removing compatibility workarounds.

  • Java 21 provides virtual threads as part of the supported API.
  • A Java 21 baseline removes reflection and conditional compatibility paths.

🧩 Java Structured Concurrency in JDK 27: A Practical Example Structured concurrency can stop related work when one task fails instead of waiting for unnecessary operations to finish.

  • StructuredTaskScope can interrupt unfinished work after a failure.
  • Virtual threads with Future do not automatically provide that cancellation behavior.

📊 Benchmarking Java Performance Of JDK 8 Through OpenJDK 27 A benchmark compares OpenJDK performance across releases from Java 8 through the recently released OpenJDK 27.

  • The benchmark covers major OpenJDK releases from 8 through 27.
  • Testing used an AMD Ryzen Threadripper 9980X workstation.

🍃 Spring Updates

🧪 ColdFusion Inside Spring Boot (One Property) Spring Boot can render existing ColdFusion templates, offering a path for modernizing applications without immediately rewriting their views.

  • Existing .cfm templates can remain part of a Spring application.
  • Modern Spring components can be introduced alongside legacy views.

🔎 Spring AI Recipe: Fact-Checking AI Responses Spring AI’s FactCheckingEvaluator compares generated responses against trusted source material, while highlighting the complexity of automated verification.

  • Generated responses can be evaluated against trusted source material.
  • Fact-checking itself requires careful handling of verification logic.

🧠 Spring AI and TypeSafe Jev: Fast, Cheap, Structured Decisions Typed decision components for routing, evaluation, ranking and other fast AI application decisions.

  • Typed decisions can support routing and evaluation in AI systems.
  • Decision components need consistent, structured outputs.

⚙️ EnvironmentPostProcessor in Spring Boot EnvironmentPostProcessor provides a way to manipulate application properties before they become available to beans.
